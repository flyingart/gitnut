The problem

Agents work in parallel. Your git client doesn't.

Without GitNut

  • SSH into each box, cd into each worktree, run git status again and again
  • No idea which agent touched which file until it is already committed
  • Reviewing a whole task means stitching together diffs commit by commit
  • A desktop git client only sees one machine, one repo at a time

With GitNut

  • Every machine, repo and worktree in one sidebar, updating by itself
  • Uncommitted edits show up seconds after an agent saves a file
  • Select an agent's commits and read the combined change, file by file
  • Commit, fetch, pull and push without leaving the window
How it works

One small daemon per machine. One window for all of them.

  1. 1

    Agents work as usual

    In repos and worktrees on your laptop, a VPS or a build box. Nothing to change in your agent setup.

  2. 2

    GitNut watches

    The gitnut daemon finds the repos, polls only what you look at, and never takes a git lock, so it can't block an agent.

  3. 3

    You see it live

    Changes stream over WebSocket to the desktop app, a browser tab, or a panel inside your own tool. Over localhost or Tailscale.

  4. 4

    You step in

    Review, commit, fetch, pull, push. Hide noisy repos, watch whole folders so new agent repos appear on their own.

Features

Everything you need to keep up with your agents.

Live

Live uncommitted changes

Every worktree's edits, updated while agents type. "All uncommitted changes" merges several projects into one tree, so three agents on three repos fit on one screen.

Review a whole task at once

Ctrl+click the commits of one task, even far apart, and read their combined change per file, with word-level highlights and IntelliJ's connector bands.

All your machines

Laptop, VPS, CI box: each runs one gitnut daemon. Group projects by server or see one flat list.

Graph

Every agent branch in one graph

Local, remote and tag refs in one IntelliJ-style graph: same lanes, colours and long-edge arrows, smooth with 80k+ commits. See where each agent branched off and what it merged.

Embed it in your agent tool

Every piece is a React component. Put <LocalChanges/> next to your agent's chat, or embed the whole client with an iframe.

Light and safe

One binary, no database, no git locks. Localhost by default, token auth and Tailscale when you open it up. Self-updates with checksums.

Screens

Feels like IntelliJ. Looks like 2026.

For tool builders

Show your agent's changes inside your own app.

Building an agent UI? Drop in one component and your users see exactly what the agent changed, live, without leaving your app.

import { LocalChanges } from "@gitnut/client";

// Live uncommitted changes of the agent's worktree, next to its chat.
<LocalChanges
  server={{ url: "http://127.0.0.1:7420" }}
  worktreePath={agent.worktree}
  theme={{ colors: { primary: "#0f766e" }, radius: { md: "10px" } }}
/>

CLI and daemon

irm /install.ps1 | iex

Installs to ~/.gitnut/bin after checking the SHA-256. Then gitnut service install and open the URL from gitnut status. Add projects in the app.
